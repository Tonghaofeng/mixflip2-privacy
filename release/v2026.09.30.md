## 一、一句话定位

小米 MIX Flip 2（国行 HyperOS 3.0.304 / Android 16 / BL 锁、不 root）的**去审查、去上报**首版：卸载/禁用 60+ 个国行组件，关闭系统级上传开关与联网检测探针，并用**手机本机常驻 VPN 防火墙（Clash Meta，always-on + 锁定）+ WireGuard 回家（Mac mini → Surge）**把删不掉的系统身份（UID 1000 安全中心/融合定位/SystemUI 等）的上报在**任何网络下**切断。验收只认底层证据，不认界面开关。

## 二、来源与构建核验

- **Clash Meta for Android 2.11.34**（附件原件）：取自 MetaCubeX/ClashMetaForAndroid GitHub Release，本地 sha256 `1ce2f78d9258358c57b47dd538ee4a94aebd8d1e6afd05f67100d3cec1ca8a9c` 与 GitHub API 公布的 digest 逐字一致。
- **策略 YAML**：由 `tools/gen_clash_config.py` 每次实时生成——包名→UID 与共享身份名（`android.uid.*`）从手机 `pm`/`dumpsys` 现取，WireGuard 密钥从 Mac mini 现取（不入库）；生成后用本机 mihomo 1.19.31 `-t` 校验（macOS 版不支持 UID 规则，校验时替换为同形规则），手机端 CMFA 导入时再做一次 Android 侧校验。含私钥的产物 `clash/` 不入库、不进附件。
- **精简清单**：`debloat/removed.txt`、`disabled.txt` 每一项都有依据（APK 内写死的服务器地址、netstats 历史流量、UID→域名实测），见 README「关键证据」。
- **Mac mini 端**：wg0 自愈守护与策略分发服务已并入 `tony/mac-mini-autostart`（提交 d06d075、a206abd，`check.sh` 69/69 全绿），本 Release 的安装套件里带其副本。

## 三、权威结果（重启后，always-on + 锁定生效）

| 项 | 结果 |
|---|---|
| 锁定模式 | 除 Clash 自身外 UID 1–99999 全部禁止走非 VPN（`dumpsys connectivity` Lockdown filtering rules） |
| 手机侧 5 分钟 | 179 条连接、拦截 41 条，**小米/国内未拦截 = 0**；被拦的：UID1000 裸 IP HTTPDNS（111.13.141.211 等）×20、idm.api.io.mi.com、resolver.msg.xiaomi.net、tracking.miui.com、ccc.sys.miui.com；下载服务 tracking；**注入 WhatsApp 进程的 sdkconfig.ad.xiaomi.com** |
| 手机侧 2 分钟复验 | 拦截 18、**未拦截 0** |
| 绕过 VPN 的直连 | 仅 Clash 自身对 DIRECT 的健康检查（Google generate_204，无身份信息） |
| 联网检测探针 | 原先每次联网都在 VPN 外探 connect.rom.miui.com + www.baidu.com；`captive_portal_mode=0` 后重连 0 新探针 |
| 出门（蜂窝） | WG 从运营商 IP 握手，15 秒 387 KB；切回 Wi-Fi 自动漫游，15 秒 207 KB |

**基线对照（精简后、上防火墙前 15 分钟）**：系统下载服务内嵌**迅雷加速 SDK**（sandai.net 上传 + P2P 节点）、查找设备 15 分钟约 20 次上报位置、UID1000 走裸 IP 绕 DNS、蓝牙→hlth.io.mi.com、账号/主题/fido→账号接口；另有一批只被家里 Surge 拦着、出门即放行。

## 四、本版改动与裁决

| 类别 | 处置 | 裁决理由 |
|---|---|---|
| 数据收集/广告（analytics、MSA、onetrack、uireporter、misight、daemon、thirdappassistant…） | 卸载 | 纯上报，无功能依赖 |
| 小爱全家、传送门/内容抓取（contentextension、contentcatcher）、HyperAI、AI 服务宿主 | 卸载 | 云端 AI/屏幕内容抓取 |
| 国行服务（浏览器、搜索、商店、快应用、黄页、云盘…）、支付卡包、车联、小米云与推送、互传/投屏(乐播 SDK) | 卸载 | 用户明确选择全删；Google 替代已装 |
| 联通终端自注册 systemhelper（夹带百度定位 SDK）、电信自注册、高通 QDMA(qcc) | 卸载 | 静态分析+流量实证 |
| 网络定位 metoknlp（高德/百度/腾讯） | 卸载 | 国行 ROM 定位 provider 写死，无法切 Google；GMS 定位与各 App 自带 SDK 不受影响 |
| 相册/笔记/计算器、锁屏画报、垃圾清理 | 整包禁用 | 小米保护（-1000）不能卸 |
| 通讯录/拨号、incallui | **保留**，隐藏图标、断网 | 系统兜底拨号器 = 紧急呼叫 |
| guardprovider | **保留**、断网 | MIUI adb/侧载安装校验依赖（实测删了装不上） |
| 安全中心（含敏感词检测、反诈引擎、云端禁装名单机制） | 保留、关开关、断网 | 删不掉（权限/应用管理/开机依赖）；其所在 UID 1000 全拦 |
| 融合定位 xiaomi.location.fused | 保留、断网 | 删了系统无 fused provider |

**过程中实测踩到并修掉的坑**：CMFA 不把 UID 交给 mihomo（UID 规则永不匹配→改 PROCESS-NAME）；WG 端点 DoH 死锁与局域网 DNS 被 Surge 劫持成 fake-ip；同一密钥双出站 endpoint 漂移；服务端回包被 Surge 改端口（出门不通）；MIUI 忽略探针 URL 设置；BPF 防火墙重启即失且豁免系统 UID；adb reverse 失效。

## 六、工作副本状态与「仓库 ≠ 磁盘」差异

- **权威仓库**：Mac mini `~/CodeVault/git/mixflip2-privacy`（→ Gitea）。**操作工作区**：Mac `~/Documents/MixFlip2-debloat`（要连 adb），用 `sync_to_repo.sh` 同步提交。
- **不在仓库里的运行态**：`clash/mixflip2.yaml`（含 WG 私钥与 API secret）；Mac mini `/opt/homebrew/etc/wireguard/`（密钥、wg0.conf）、`~/phone-config/`（token 与分发中的策略）、`/var/log/wireguard-home.log`；路由器静态转发 `wireguard 51820/UDP`。
- **手机当前状态**：Clash 配置「MixFlip2」（URL 指向 Mac mini 分发点）运行中、always-on + 锁定；`captive_portal_mode=0`；小米账号**尚未退出**（需用户在手机上输密码）。

## 七、复现步骤

见附件 `install_kit` 里的 INSTALL.md：0 前提 → 1 精简（removed/disabled 照单执行）→ 2 系统设置 → 3 Mac mini 起 WireGuard 与分发点、路由器转发 → 4 手机装 Clash、导入策略、always-on + 锁定、**重启** → 5 `accept.py 300` 验收（未拦截必须为 0）+ 断 Wi-Fi 走蜂窝复测。
