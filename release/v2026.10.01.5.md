# v2026.10.01.5 — 删除病毒扫描/云扫描/电诈防护引擎 guardprovider

## 一、一句话定位

手机突然弹「超 7 天未扫描病毒」，点进去要「上传应用包名和应用特征到云病毒引擎」。本版把背后的引擎 `com.miui.guardprovider` 整包卸载，掐掉提醒判据，电诈防护全部开关显式置 0，全部纳入开机体检。另外实测并记录了「设置→隐私与安全→安全」页上「电诈防护」和「手机管家」两个入口无 root 删不掉的原因。

## 二、来源与核验

- **弹窗来源**：`dumpsys notification` 显示通知 id 1012「您已超7天未进行病毒扫描」，来自 com.miui.securitycenter，20:02 和 22:08 各发一次。`usagestats` 记录 22:02:16 进入 `com.miui.antivirus.activity.MainActivity`，3 秒后退出。复现时 uiautomator 读到弹窗原文：「使用云扫描：为了提升病毒扫描能力，我们会上传应用包名和应用的特征至云病毒引擎进行扫描；本功能使用了合作方提供的杀毒引擎」。
- **反编译**（jadx，安全中心 MIUISecurityCenter.apk、Settings.apk、framework.jar、services.jar，均从本机拉取）：
  - 提醒函数 `r.G()` 只读 `secure key_latest_virus_scan_date`，值 ≤0 或距今 ≤7 天就 return；这个键只在扫描完成时写入
  - 前台扫描、后台 `VirusScanJobService`（job 210610）和病毒库更新 `VirusAutoUpdateJobService`（job 99）都 bind guardprovider；安全中心本体里没有第三方杀毒 SDK
  - guardprovider 持有截获通话音频（CAPTURE_VOICE_COMMUNICATION_OUTPUT）、全盘文件（MANAGE_EXTERNAL_STORAGE）、写安全设置、查询全部应用等特权；「AI 反诈守护」开启时还会被授予 RECORD_AUDIO
  - 电诈防护开关全部定位到具体键（见 `debloat/antivirus_antifraud.md` 表格）
- **删前安全检查**（htmlviewer 事故的铁律）：guardprovider 提供 3 个 authority（`guard`、`com.miui.guardprovider.virusscan`、androidx-startup），`dumpsys content` 里没有任何进程对它们注册观察者。安全中心三个进程都是 `*APP*`，不是常驻进程。
- **重启验证**：卸载 22:31:40，等待近 3 分钟后执行 `svc power reboot`，22:35:02 开机完成。`WATCH=90 tools/postboot_check.sh` 全部通过：removed.txt 91 个全部未装，开机后没有系统级崩溃，SystemUI pid 稳定，VPN 锁定在线。合入远端 Clash 防强停检查后又跑了一次，同样全部通过。

## 四、仍保留与理由

- **「电诈防护」入口**：显示判据只有 `isVoiceCapable()`，改它等于不能打电话。改页面 XML 需要覆盖层，但安全中心没有声明 overlayable；shell 造 fabricated overlay 又被 OMS 写死拒绝（`callingUid == 2000 → "Non-root shell cannot fabricate overlays"`，b/202768292，cmd 和 binder API 都拦）。
- **「手机管家」入口**：判据是只读属性 `ro.miui.support.system.app.uninstall.v2`，并且要求未安装 `com.miui.securitymanager`。按「自写空壳顶替」思路构建了空壳包，经 Chrome 交给小米安装器后被系统拒绝：`FAILED_VERIFICATION_FAILURE SIGNATURE FAIL`（安装器报 -22），即 MIUI 对小米保留包名做签名强校验。
- 两个入口现在都是死壳：引擎已删，开关全关，所在身份无网。
- 安全中心、小米安装器本体：UID 1000 / 系统安装器，删不掉也不该删，只断网。

## 七、复现

```bash
adb shell pm uninstall --user 0 com.miui.guardprovider
adb shell settings put secure key_latest_virus_scan_date 0
for k in com.android.browser.web_page_warning_states ai_guard_function_switch \
         com.miui.guardprovider.AI_GUARD_PRIVACY_AGREEMENT optimizer_scan_cloud; do
  adb shell settings put secure $k 0; done
adb shell settings put system cloud_antispam 0; adb shell settings put system key_yellowpage_main_switch 0
adb shell cmd jobscheduler cancel -u 0 com.miui.securitycenter 99
adb shell cmd jobscheduler cancel -u 0 com.miui.securitycenter 210610
# 等 ≥3 分钟后：
adb shell svc power reboot
WATCH=90 tools/postboot_check.sh
```
回滚：`debloat/antivirus_antifraud_restore.sh`。
