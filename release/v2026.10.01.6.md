复盘全文在 `debloat/复盘_20261001_病毒扫描漏网.md`，待办表在 `debloat/OPEN_ITEMS.md`。

## 二、来源与核验

- **Play 保护机制**：`global package_verifier_user_consent` 1 → **-1**（扫描应用开关）；`global package_verifier_enable` null → **0**（装 App 时不再交给谷歌验证）。读回无误，体检已纳入。保护机制页的界面读回没做成（商店深链接只到首页），请用户在商店里看一眼。
- **功能面审计**（`tools/feature_audit.py`，只读）：盘点 user 0 已装的 144 个厂商包的敏感/特权权限、JobScheduler 任务、闹钟、近 7 天通知、高权位（无障碍/通知监听/设备管理/默认角色），以及开着的同意/云/上报类键。结果在 `evidence/feature_audit_20261001/audit.json`。
  - SystemUI 一周 177 次 `safemode_notification`：全部集中在 10-01 07 点 htmlviewer 事故期间，属于历史
  - 高权位干净：无障碍只有 Bitwarden，没有通知监听，没有设备管理器，默认角色全是谷歌
- **网络验收**（accept.py，300 秒空闲）：198 条连接，小米/国内/裸 IP 未拦截 0 条；绕过 VPN 只有 1 条，是 Clash 自身 DIRECT 健康检查（预期）。
- **注意**：`dumpsys netstats` 会把经 VPN 的流量倒记到底层网卡，**不能**当作绕过证据。本版没有用它下结论。

## 四、仍保留与理由

- **registration 不删**：常驻进程 `com.android.phone`（*PERS*）正绑着它的 RegistrationService。全盘扫描特权 APK 和框架 jar，只找到两处字符串引用（短信控制器白名单、system_server），都不是绑定代码，无法证明删后电话进程开机不崩，属于 htmlviewer 同类风险。appops 改不动：权限是 SYSTEM_FIXED，会被同步回 allow（日志 `runtime op … should not be set directly`）。
- **系统身份绕过 VPN 锁定**（体检 §3c）：无 root 无解；在家有 Surge 兜底，走蜂窝时没有观测手段。
- **谷歌侧**（Wi-Fi 常扫描、Chrome 遥测、OFFLINE_FIND_SCAN）：谷歌生态是用户自选的，列入待办等用户决定。
