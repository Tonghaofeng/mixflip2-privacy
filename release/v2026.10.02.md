# v2026.10.02 — 后台隐私与遥测排查：Google 定位准确性关闭、公开设置里的标识符清除、谷歌遥测端点拦截

## 一、一句话定位

用户纠偏：「我们主要是处理隐私问题，特别是背后的那种隐私问题和遥测」。本版只从**后台实际行为**出发，不看界面入口：
- 开机后的全量外联，被拒的也算
- 遥测 SDK 落在哪些进程
- 所有 App 都能读的设置里残留了哪些标识符
- 谷歌在后台采集什么

查出四件真问题：三件已处理，一件（谷歌备份）等用户决定。证据文档：`debloat/background_telemetry_20261002.md`。

## 二、来源与核验

- **外联**：23:48:43 重启后约 10 分钟，按「进程 → 目标 → 动作」聚合 CMFA 日志（`evidence/background_20261002/boot_connections.txt`）。小米侧全部被拒，但都还在尝试连接：
  - 相机 → mcc.inf.miui.com，34 次
  - UID 1000 → tracking / api.sec / adv.sec / xmpush 注册 / ccc 云控，22 次
  - 下载服务 → 迅雷 sandai 与广告 SDK sdkconfig.ad.xiaomi.com，15 次
  - 权限管理、蓝牙 CDN 若干

  谷歌侧在放行：GMS → doubleclick、footprints-pa、play.googleapis.com。
- **SDK 落点**：用日志按 pid 反查（`telemetry_sdk_processes.txt`）：
  - xmpush 在 securitycenter.remote、htmlviewer:pushservice、camera:pushservice 三个进程里
  - OneTrack 在 system_server、securitycenter.remote、蓝牙进程里
  - system_server 反复报 `Unable to start service com.miui.analytics/.onetrack.TrackService: not found`，说明系统层埋点的总收集器已删，交不出数据
- **标识符**：扫 global/secure/system 表里形似 UUID、长十六进制串、数字 ID 或键名像标识符的值，再用 `dumpsys settings` 的 `pkg:` 字段查写入方。
- **谷歌定位**：`dumpsys location` 显示 GMS 在被动定位源上挂着两个 `hiddenFromAppOps` 监听；`content://com.google.settings/partner` 中 `network_location_opt_in=1`。shell 写 partner 表被拒，需要 `WRITE_GSETTINGS`。

## 三、结果

| 项 | 前 | 后 | 证据 |

| Google 定位准确性 | 开（1） | **关（0）** | 经 GMS 设置页关闭，partner 表读回 `value=0`；开机体检新增此项 |
| `global ad_aaid`（小米广告 ID，任何 App 可读） | 有值 | **已删** | 写入方 com.miui.analytics 已删，不会再生成 |

| `secure antispam_sync_token` / `antispam_water_mark` | 有值 | **已删** | 同上 |
| 谷歌遥测端点 12 个后缀 | 放行 | 策略已发布 | mihomo -t 通过、分发点 HTTP 200；**00:05 探测手机端尚未更新** |
| 开机体检 | — | 全部通过 | `WATCH=3 postboot_check` |

标识符原值存在本机 `raw_private/`，不同步、不入库。

## 四、仍保留与理由

- **谷歌备份**：短信、彩信、通话记录在上传云端。关掉会丢掉换机恢复能力，等用户决定（整体关闭：`bmgr enable false`）。
- **相机 / htmlviewer 的推送进程**仍在后台尝试连接，全部被拒。htmlviewer 是 SystemUI 开机必需，不动；相机可以考虑后台限制。
- **配对蓝牙设备的 MAC 明文**存在 `global miui_bonded_device_account_key`。写入方是在用的蓝牙栈，删了配对时会写回，没有根治办法。
- **`play.googleapis.com`** 不拦：Clearcut 日志和 Play 商店下载用的是同一个域名。
- README「已知限制」第一条已更正：lockdown 只约束普通 socket，持系统网络权限的身份显式绑定物理网卡可以绕过。
